ORBIT 地理实验室 · Windows 使用说明

1. 下载完整 ZIP 文件。右键 ZIP → 全部解压缩 → 解压。
2. 打开解压后的 ORBIT-Windows 文件夹。
3. 双击“启动地理实验室.bat”。不要在 ZIP 里直接双击。
4. 如果打开了 Node.js 官网，请下载并安装 Windows 版 LTS（普通 Intel/AMD 电脑选 x64）。安装完成后，关闭黑色窗口，再次双击脚本。
5. 如果电脑已装有 Node.js 18 或更新版本，会自动启动并打开浏览器，无需安装 npm 依赖，无需管理员权限。
6. 浏览器中会出现地球界面。拖动旋转、滚轮缩放、点击地表选择观测点。底部点击播放，或拖动 UTC 时间轴。
7. 使用时保持启动窗口开启；关闭窗口即可停止软件。以后使用时再双击脚本即可。

若浏览器没有自动打开，请复制启动窗口显示的 http://127.0.0.1:端口/ 地址到 Edge 或 Chrome。
默认端口为 5173，若已占用会自动选择其他可用端口，请以窗口显示为准。
无需改动 Windows 执行策略。若 Windows 显示安全提示，请先确认文件来自你自己请求制作的项目；不确定时把提示截图发给助手。

说明：这是本机运行包，只有你的电脑可以访问。应用本身不需要联网，安装 Node.js 时需要联网。
此包附带源码；dist 为构建好的网页，修改源码后需要在开发环境重新构建才能更新网页。
