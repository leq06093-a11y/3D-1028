# ORBIT · 地理实验室

React 19、Tailwind CSS 4、Three.js 构建的交互式地理教学应用。

## 开发

需要 Node.js 22.12+（当前环境为 Node.js 24）。

```sh
npm ci
npm run dev -- --port 5173
```

生产构建：`npm run build`，本地预览：`npm run preview`。

## 操作

- 顶部切换地球中心、公转全景与太阳直射点视角。
- 拖动旋转，滚轮缩放，点击地球选取观测点。
- 左侧控制赤道、回归线、晨昏线、经纬网与视觉效果；近日点/远日点标记位于公转侧视图。
- 底部选择自转或公转播放速率，再点击播放；支持 1x / 2x / 10x。自转模式 1x 每秒推进 30 分钟，公转模式每秒推进 12 小时。两种模式均同步计算自转、公转。
- 时间轴覆盖 2026 年，所有时间均为 UTC；观测点数据、当日高度角曲线、昼夜地图和公转示意随时间更新。

## 教学模型与限制

地轴倾角固定为 23.5°，采用近似太阳黄经、赤纬与格林尼治恒星时计算太阳高度角，不含大气折射、地形与岁差修正。地球始终保持在画布中心；公转全景使用相对运动表现日地关系，天体尺寸和轨道距离为压缩示意，侧视图非等比例。不可用作精密天文历算。

纹理已保存到 `public/textures`，运行时无需请求第三方图片：日间、高光、云层来自 turban/webgl-earth 的公开示例纹理；夜间纹理来自 mrdoob/three.js 的公开示例素材。发布前请确认素材的适用授权和署名要求。

## Windows 双击运行包

下载 [ORBIT-Windows.zip](https://github.com/leq06093-a11y/3D-1028/raw/refs/heads/main/downloads/ORBIT-Windows.zip)，右键选择“全部解压缩”，打开解压后的文件夹，双击“启动地理实验室.bat”。需安装 Node.js 18+；未安装时脚本会打开 Node.js 官网。无需安装项目依赖。使用期间保持启动窗口开启。

包内附带构建后的网页和中文说明，详见 `Windows使用说明.txt`。
